# Local study plan

The two-flag pilot ran first. Its 128-update model never emitted a decision on 96 held-out decision prompts. That result motivates the following exploratory interval experiment. Development and test cases were generated before training. All proposed claims apply to the named synthetic distribution.

1. **Interval calibration**. Start fresh with width 16, seed 12, batch 12, Adam at 0.003, 128 updates. Include ordinary authored text and the full token sequences of both valid and invalid shipment cases. Use the same tokenizer and example sampler for every arm. Record full per-case raw greedy outputs for up to 24 tokens, including ordinary prose.
2. **Matched experiment**. Fork the same 128-update checkpoint into a one-block continuation, a one-block Adam reset at unchanged learning rate, and a two-block expansion. Train an independent two-block model from initialization on the identical sampled examples. Compare first at 256 total updates. The forced expansion exercises the mechanism before an observed plateau. If a slice completes early, a further comparison at 1,024 total updates on the same four trajectories will reveal whether an early ranking was transient. Stop earlier for execution errors or local limits.
3. **Primary tests**. Inspect unsupported confirmations, the number of supported prompts receiving an actual confirmation, exact full continuations, and paired responses when the query changes but all receipts stay fixed. Interpret route-substring matches as a weak secondary diagnostic. Record generated words, not just logit rankings. Report development and held-out prose loss separately from synthetic-task loss. A single seed can falsify a universal claim but cannot establish a growth advantage.
4. **Comparators and cost**. Number of updates and ordered tokens match across arms at each stage. Larger models receive more compute per example. Report cumulative parameter-target products, time, and time spent at final width. For a scaling advantage, add a separately matched compute budget, multiple seeds and a strong unconstrained language-model baseline on the same corpus and task. The earlier standalone GRU experiment used different inputs.
5. **Plateau-conditioned growth**. At least 1,000 updates and five development observations are required for the default trigger. Relative development loss span and decrease must be within 1% and the exact useful-response rate must span no more than one percentage point. If performance is near zero, classify that as a stalled model and test the data or architecture; absence of improvement alone is insufficient to request a larger GPU. Development history drives this arm. Reserve fresh unseen task families before making a confirmatory generalization claim.

The present corpus contains eight original normal-prose training passages. It can expose language-interface errors but cannot support a claim of general language proficiency. A distinct earlier run on the Omen used a 68,439-token external train-only prose pack and different models. Those checkpoints have no role in the from-initialization certificate.
