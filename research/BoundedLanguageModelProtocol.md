# Bounded language-model test: protected learned binding before the sink

## Question

Does the *trained recurrent computation that the decoder actually uses* carry the evidence needed to fill a new typed request, and can optimizer updates and approved width/depth growth preserve old mandatory responses? Successful checker rejections or a parallel solver picking the answer do not count.

The existing fitted observer proof and StructuralSSMWired fixture are reference targets, not results for the model below. The prior LP and nested-DAG timing results argue against learning their deterministic solver tasks.

## Fixed semantics before training

Use a synthetic, controlled-byte vocabulary with a distinct authenticated event channel. Raw prose/quoted role markers never produce that channel. A verified tokenizer/parser maps byte records to **lexical/typed events only**. It must not resolve requested entities or derive final answers. Keep immutable provenance, account, grant incarnation, policy version, and clock/frontier outside model-written storage.

Build three Boolean facts per named scope, with authoritative relation records for L = x XOR y and R = y XOR z. Support typed enter/observe, identity-scoped flip/change, keep, invalidate, and explicit ambiguity. Keep two device identities, document revisions, and role mappings in separate independently versioned fields. Old family asks for the backed direct relation L; new family asks for x XOR z, or an unseen composition attaching the backed relation to a scope-bound updated document. Actions are exact immutable ASTs, never unconstrained text. Model proposes them; sink checks current scope/epoch and exact payload. The sink cannot replace a referent, fill a missing argument or supply an answer.

Mandatory profiles: (a) old direct relation with valid live evidence/grant; (b) post-growth composite request when both relations are uniquely known; (c) paired opposite-result histories with identical bytes/suffix, scope and dual-valid authority. A missing factor, unresolved alias, stale evidence, or revocation forces named DEFER/CONFIRM, never a protected effect. Display-only prose is explicitly outside the operative meaning contract.

## Model and arms

* Small selective recurrent/SSM observer executes the equivalent of quantized bounded rows (or a certified convex dictionary). Train the recurrence and query head; keep fixed numeric half-space/cell guards. Use separate nuisance/prose/attention channels with only a checked bounded feedback port. The operative decoder does not receive the raw evidence log, a reference solver output, or semantic mode labels.
* Train with usual next-token loss plus optional prefix property/provenance supervision. Use unconnected nuisance loss as a control. Pretrain away from final composed query labels. No target endpoint on either input stream. Give one withheld operational query form that recombines already supervised fields rather than simply renaming XOR.
* Compare ordinary pretraining, prefix-supervised only, prefix-supervised plus structural projection, same unconstrained model plus admission wrapper, and exact minimal state-machine/relational oracle. Compare same slot count, inference budget, and data. State exactly which semantics were specified.
* After fitting, export exact parser/model/op order/weights/port graph. Grow new observer, optionally add nontrivial protected hold depth, and vary state-dependent router. Compare with an equal-compute trained-from-scratch larger model. Old arm observes same input interface and cannot use new facts by shortcut. Revoke before a fresh growth query; require stale rejection and fresh recovery.

## Data ownership and split

Use an isolated deterministic generator for development fixtures only; no qualification data, shared model checkpoints, or GPU. Prespecify whole trajectory seeds, alias/position/evidence-source symmetries, no correlated duplicates across splits. Hold out legal event-order motifs (same event multiset with different order), long suffixes and scope/version transitions; test all endpoint parities conditional on each entire single stream. Add quoted fake event/role markers, wrong tenant, late tombstone, malformed/trailing byte/UTF-8, stale install, same-epoch evidence supersession, cache revocation and near-interval boundary cases. Preserve deliberately ambiguous cases rather than rejecting all hard points from the denominator.

## State interventions (measure before sink)

1. Matched same-request/authority twins differing only in a lawful authenticated observation: both must voluntarily emit different **correct** ASTs.
2. Swap only certified protected states while preserving all nuisance/prose state, cache IDs and current authority. Raw AST changes accordingly. Swap nuisance/prose: protected result unchanged where specified. A lawful invalidate/reset removes the backed answer; fresh true evidence restores it. Do not rely on off-manifold zeroing.
3. Ablate each evidence factor, freeze learned recurrence, force DEFER-only, shuffle prefix supervision, allow a wrapper to reject, and compare the exact oracle.
4. Compare at least two functionally distinct admissible states/updates. Same mandatory semantics cannot become optimizer-dependent by construction. Measure optimization causality separately on optional valid proof routing, completion latency or other predeclared utility.

## Proof and execution audit

Check each source/target region × input class × effective parameter/roundoff envelope for the executable learned recurrence. Prove mixed inference/update/width/restore closure and old required completion, not just final-state correctness. Depth contract only adds modeled protected-state-preserving blocks; reserve the same external response budget, accounting for computation rather than defining eligible ticks by willingness to answer. Cache, evidence epochs and query context must be current after migration, and whole index/serializer consume the exact checked effect.

Trace the actual deployment from bytes to protected channel, exact numerical semantics, internal decoder, immutable AST serialization, and commit. A finite table correspondence is valid only for its named kernel; no unproved GPU/FMA/FTZ/overflow behavior. For deterministic argmax certify strict comparisons; finite logits in ordinary softmax do not give zero forbidden support. Run formal proof kernel (not just native evaluation), audit axioms, independently replay and try deliberate mutations. No end-user action/authority claims if the actual-world trust/implementation bridge is missing.

## Decisive outcomes

* Reject if no actual deployed package passes exact stage checks, a wrapper supplies the answer, old eligible coverage regresses, new legal histories still defer, state interventions are inert, or quota/latency can be gamed by indefinite progress suspension.
* Report certificate coverage over a stated full admitted class separately from held-out sample metrics; raw correct AST, unsupported proposal and admission outcomes separately; ordinary loss, checked update fraction, numerical robustness, footprint and latency.
* A valuable positive is higher credible surface-language/relational composition coverage or better proof/resource cost than the exact/compiler baseline under the same trust contract. A fitted bounded fixed-function implementation alone is a structural result, not a reason to pretrain a large model.
