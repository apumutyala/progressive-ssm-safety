# Analysis

## What the experiments support

The strongest result is **exact retention of an existing execution path while added capacity learns something new**. The evidence is stronger than a standalone before-and-after score: the narrow controls fail on the new work, the wide and offline controls show the task is learnable without the growth schedule, and removing or replacing the new state removes the gain. The controls rule out some easy explanations, not all. In particular, the experiments do not establish better training efficiency, a broadly reusable skill, or a scaling law.

The language experiment tests a different proposition. A recurrent branch that changes the full ordinary-token score vector can improve average text prediction without disrupting the old route. But the evidence-trained branch learned an answer-like shape without learning to track the relevant fact. Better language-model loss, attractive completions and even a correct-looking answer on one side do not imply sensitivity to evidence. Balanced pairs require correctness on both sides. A changed output alone is not a pass.

## What the architecture guarantees

1. **Eligibility, conditional on the input contract.** On the typed specialist, the finite learned action scores are bounded in `[-1, 1]`. When authenticated current records are insufficient or conflict, the Clarify score is `+2`, above every learned action score. On a complete record the architecture does not prove that the preferred action is right. It cannot authenticate a sentence merely because the model reads or generates it. See [the original model's separate decision proof](../../PROOF.md) for the reserved-token claim.
2. **Retention, conditional on isolation.** If growth leaves the legacy weights, buffers, cache semantics and executed arithmetic unchanged, and legacy routing bypasses the new branch with no writes back, a step of the old recurrence is unchanged. Induction gives equal states and scores on the same prefix. Deterministic decoding then gives the same continuation with the same initial state and tie-breaking. Sampling would also require the same random draws; it was not certified here. A zero-initialized contribution alone does not prove retention after training: shared normalization, tied mutable embeddings, optimizer decay and stale caches are examples of ways the premises can fail. Fixed-input byte checks support but do not fully prove code-level correspondence.
3. **Semantic scope is separate.** If two admissible interpretations have identical observed text and follow-up answers but imply different authorizations, no learner using only those observations can always give the correct definite decision. More training cannot supply absent evidence. A design worth testing is to let the model propose a reading, then require independently checked scope and current evidence for a consequential action. An ambiguous withdrawal would block actions whose authorization depends on a possibly withdrawn record, not actions independent of it. This is a proof direction, not an implemented guarantee for natural language or real effects.

## Next discriminating experiment

The first comparison against a fully trainable copy did not rescue even the familiar panels at its matched budget. More tellingly, giving the model the correct fact directly did not rescue its output. The next step is to compare copying a supplied color as the first answer token versus copying it after the fixed answer prefix. Trace the color swap through tokenization and target alignment, the recurrent state and the final color-token scores. Compare ordinary cross-entropy with a loss on the color token only. A probe or oracle at the readout can test whether the model forgot the fact or retained it without using it. Delay bigger runs until that simple distinction is clear.

Do not promote a checkpoint on lower prose loss alone. A result worth building on must improve held paired correctness without weakening the scoped guarantees. No result here establishes that ordinary generated language is generally truthful, safe or aligned.
